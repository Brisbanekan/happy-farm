# 莊園裝飾素材

商店「🏡 裝飾」分頁賣的東西。裝飾**不影響任何遊戲數值**，純粹擺著看 ——
它存在的目的是當金幣的出口，所以可以放心加，不會破壞平衡。

---

## 換掉一張圖

直接覆蓋這個資料夾裡的同名 PNG 就好，程式不用動。

| 檔名 | 遊戲內名稱 |
|---|---|
| `log.png` | 木樁 |
| `rock.png` | 岩石 |
| `bush.png` | 灌木叢 |
| `flower_pink.png` | 粉花圃 |
| `flower_white.png` | 白花圃 |
| `tree_small.png` | 小樹 |
| `tree_oak.png` | 橡樹 |
| `tree_pine.png` | 松樹 |

### 圖檔要求

- **PNG，透明背景**（不要白底，會出現白色方塊）
- **直立正面視角**，不要等角／俯視 —— 主遊戲的背景是手繪平視
- **底部貼齊內容**：程式以「底部中心」為錨點把它種在地上。
  圖片下方若留了空白，看起來就會浮在半空
- 寬度 256px 左右即可，太大只是拖慢載入

> 現有這幾張是從 `happy-farm-iso/building/d_*.png` 複製過來的。
> 那邊是等角版本在用的，兩邊已經**各自獨立** ——
> 改這裡不會影響 iso 版，改 iso 版也不會影響這裡。

## 加一款新的

1. 把 PNG 丟進這個資料夾，例如 `windmill.png`
2. 打開 `happy-farm.html`，搜尋 `const DECOS=[`
3. 複製一行改掉：

```js
{k:"windmill", n:"風車", img:"deco/windmill.png", w:110, cost:3000000},
```

| 欄位 | 說明 |
|---|---|
| `k` | 內部代號，存檔用。**訂了就不要再改** —— 改了等於玩家買過的那款憑空消失 |
| `n` | 商店與農場紀錄裡顯示的名稱 |
| `img` | 圖檔路徑 |
| `w` | 畫在農場上的寬度（px），高度自動等比。實際還會依遠近再縮放 0.65～1.0 倍 |
| `cost` | 首次售價 |

陣列的順序就是商店裡的顯示順序。

---

## 調整價格

改 `cost` 就好。同一款重複購買時，價格會乘上 `DECO_STEP`（目前 1.6）：

| 購買次數 | 價格 |
|---|---|
| 第 1 次 | cost |
| 第 2 次 | cost × 1.6 |
| 第 3 次 | cost × 2.56 |
| 第 5 次 | cost × 6.55 |

這是刻意的 —— 讓裝飾成為**永遠花得完**的金幣出口。
覺得太陡或太平，改 `const DECO_STEP=1.6;` 那一行。

## 擺放位置

**玩家買了之後可以自己擺。** 左下功能選單 →「🏡 擺設」開啟擺設模式：

- 拖曳裝飾調位置，放開就存檔
- 每件右上角有 × 可以收起（收起不退錢，要重買）
- 擺設模式中不會誤開建築物面板、也不會拖到整個世界

每一件都是獨立實例（`G.decoItems = [{k, x, y}, ...]`），各自記著自己的座標。

### 剛買到時的預設位置

搜尋 `const DECO_SLOTS=[`，那是 16 組 `[x, y]`，
座標系是世界內容區 **1400 × 1000**，**錨點為底部中心**。
玩家可以拖走，這只是「剛買到時先放哪」。

這些座標不是隨手挑的，是程式掃出來的 —— 排除掉：

| 物件 | 佔位（左, 上, 右, 下） |
|---|---|
| 倉庫 | 49, 247, 354, 454 |
| 農舍 | 606, 340, 988, 609 |
| 狗屋 | 944, 494, 1016, 561 |
| 工廠 | 36, 524, 438, 768 |
| 田地 | 656, 594, 1294, 850 |
| 田影 | 695, 747, 1255, 867 |

再扣掉最大裝飾尺寸與邊距，並要求頂端不低於 `y=245`（否則會長到遠山和天空上）。

超過 16 件時，會從第一格重新排並往右下錯開 26 / 18 px。

### 拖曳的邊界

`decoBindDrag` 裡夾在 x 30~1370、y 260~990 —— 防止拖出世界或飛到天空。
要放寬改那兩行。

### 景深

裝飾會依 y 座標縮放（`decoDepth`）：y=430 時 ×0.65、y=960 時 ×1.0。
不做這件事的話，拖到遠處的東西會像浮在半空。
z-index 也依 y 排序，所以近的會蓋住遠的。

## 為什麼不用 emoji

第一版用 emoji，有兩個問題：

1. 風格跟手繪背景不搭
2. 更嚴重的是它沿用了 `.deco` 這個 class，
   而 `#world .deco` 被設成 `display:none`（背景圖本身已經畫了樹和雲），
   所以那些裝飾**根本不會出現在畫面上**

現在用的是獨立的 `.owndeco` 樣式。
